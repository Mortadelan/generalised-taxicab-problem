# Generalised Taxicab Problem

a general exploration of the generalised taxicab problem, starting with Taxicab(5, 2, 2).

all code is written by me, but assisted by ChatGPT.

the math is rather divided between ChatGPT doing more concrete mathematics and me suggesting ideas like "what if you simplify a^5 + b^5 = c^5 + d^5 into x^5 + y^5 = z, and then we map x, y and z to a 3D space".

the first exploration relates to that idea, exploring the values of z mod 11
